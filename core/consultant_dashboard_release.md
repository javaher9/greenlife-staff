# Consultant Cockpit v1

- Desktop consultant root redirects to `/consultant/`.
- Uses real branch appointment, lead, finance, task, notification and internal-message data.
- Includes fixed quick chat access to existing internal staff messaging.
- Includes Happy Call queue from completed visits in the prior 21 days.
- Includes CEM-oriented customer card with spend/loyalty preview.
- Includes patient-facing presentation mode and safe before/after placeholders.
- Does not fabricate device/cabin/operator resource assignments; that scheduling engine remains the next phase.
