# GreenLife Staff v3

این نسخه ماژول‌های اصلی Staff را به نسخه Report اضافه می‌کند:
- داشبورد نقش‌محور
- وظایف کارمند و مدیریت وظایف
- اطلاعیه‌ها
- درخواست مرخصی/ماموریت و تایید مدیر
- شرح وظایف و SOP
- فهرست و ایجاد کارمند
- پروفایل
- گزارش متنی و صوتی و آماده اتصال AI

## نصب روی نسخه فعلی
فایل `.env` فعلی را حفظ کنید، سپس:
```bash
docker compose down
docker compose build --no-cache
docker compose up -d
```
Migration شماره 0002 خودکار اجرا می‌شود و اطلاعات قبلی گزارش‌ها حفظ می‌شود.
